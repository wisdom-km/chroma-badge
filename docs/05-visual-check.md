# 3D / 截图：先分清「拍错了」还是「板上真有问题」

给 Wisdom 和之后任何模型。**3D、渲染、截图看不清时，禁止直接说「没法 100% 断定」或把猜测当板上问题。**

每次遇到「图上看起来不对 / 不确定插口朝哪 / 字是不是叠了」这一类问题：

1. **先读本文**（含下面的案例）。
2. **再查源文件**：`hardware/pcb/scripts/design.py`（事实来源）、`badge.kicad_pcb` 焊盘/丝印坐标、必要时封装 3D。
3. **证据要对准目标**。近景必须能认出那个元件；拍到绿油、过孔、电池仓角，等于没拍。
4. 自己先下结论，只分两种：

| 判定 | 你怎么做 |
|---|---|
| **拍错了**（相机/pivot/镜像/看的层不对） | 自己重拍、自己核对。不要当成板上缺陷去问，更不要动铜皮。 |
| **板上真有问题** | **先问 Wisdom，讨论后再改。** 不要自行 `gen_pcb.py` / 重布。 |

不确定就再拍一次、再对一次坐标，直到能指着图说清。还是分不清，把「源文件怎么说 / 图上看到什么 / 还缺哪一张对准的图」一起问，不要用含糊句结束。

新踩的坑写进本文「案例」节，再推 GitHub。不要只留在对话里。

## 渲染怎么才算拍到了

元件全在 **B.Cu**。看背面用 `kicad-cli pcb render --side bottom`。

- 板 91×84 mm，中心约 `(45.5, 42)` mm。
- `--pivot` 是相对板中心、单位 **厘米**。PCB Y 向下；3D 的 Y 通常相反。
- 目标 `(x, y)` mm：`dx = (x - 45.5) / 10`，`dy = -(y - 42) / 10`。
- 例：J1 `(40, 73)` → `--pivot "-0.55,-3.1,0"`，`--zoom 7`～`10`。
- 交图前自检：图上要有目标丝印/外形（如 `J1`、棕色翻盖），不能只是一块绿油。

Windows：`%LOCALAPPDATA%\Programs\KiCad\9.0\bin\kicad-cli`。图放 `hardware/pcb/output/`（`render_back.png`、特写另存）。

全板背面看不清细节时，必须再出一张 **对准的特写**，不能靠全板缩略图下机械结论。

## 案例

以后同类事先对这两条。新案例往下追加。

### 2026-09-14 J1 翻盖哪边是插口

- **当时说法**：「3D 没法 100% 断定翻盖哪边是插口。」
- **实际**：第一次近景 pivot 没对准 J1，拍到的是绿油和过孔。**拍错了，不是座子装反。**
- **源文件**：`J1 at=(40.0, 73.0, 0)`，槽 `FPC_SLOT=(27.0, 77.6, 57.0, 79.6)`。FH12 棕色是翻盖，FPC 从翻盖侧插入。
- **对准后的图**：银色焊脚朝 ESP，棕色翻盖朝槽。开口朝槽，**不用转 180°**，不用重布。
- **教训**：没拍到目标就不能下「不确定 / 可能要转 180°」这种结论。

### 2026-09-14 NFC 线圈 3D 不黄

- **当时**：Wisdom 红框里的线圈是黄线，重渲的 `render_back.png` 没有黄线。
- **实际**：铜皮还在，**不是拍丢、也不是线圈没了。** ANT1 pad 1 仍是 11 圈螺旋，现板层只有 `"B.Cu"`（无 Mask）。盖绿油之后，实物和光线追踪里线圈被阻焊盖住，看起来是绿的；黄/金 = 开窗露铜（沉金）。圈内那颗小黄点是仍开窗的通孔 pad 2。
- **你红框里发黄**：多半是 KiCad 3D/编辑器按铜层颜色画（B.Cu 默认偏黄），或盖绿油之前那版渲染。`kicad-cli pcb render` 默认 `follow_plot_settings`，按加工后外观画，所以不黄。
- **对准的图**：`hardware/pcb/output/nfc_coil_close.png`（绿线圈 + 一颗金通孔）。
- **教训**：3D 少了「铜的黄」先对 Mask：有铜无窗 = 应该绿。不要为了渲成黄色去把 Mask 加回去。

### 2026-09-14 FreeCAD 装配全灰、不像板渲染

- **当时**：Wisdom 把 FreeCAD `badge_assembly.FCStd` 和 KiCad `render_back.png` 并排：装配灰、正视、几乎看不出零件；板渲是绿油+元件。
- **实际**：**不是没开对功能，也不是外壳没做。** 图2 是 `kicad-cli pcb render` 光线追踪（只渲 PCB）。图1 是机械装配：前框/后盖按 3D 打印件做成深灰实体，用来对尺寸和干涉，不是产品效果图。脚本里有颜色（框深灰、屏米色、板绿），但 `freecadcmd` 无 GUI，`ViewObject.ShapeColor` 写不进 `.FCStd`，打开就全是默认灰。选中零件会变成亮绿（FreeCAD 选中色），不是屏本身是绿的。
- **怎么看**：关掉右侧 Transform；右上导航立方点角变成斜视，或中键拖旋转。左侧树：`FrontFrame` / `BackCover` / `EPaperPanel_4p2` / `PCB_from_KiCad` / `LiPo_2mm`，取消勾选就能透过看。板外观仍以 `hardware/pcb/output/render_back.png` 为准。
- **教训**：FreeCAD 装配素 ≠ 外壳没设计。要看绿油/丝印/线圈用 KiCad 渲染；要看开窗/USB/按键孔用 FreeCAD 转角度、开关零件。

### 2026-09-14 B.Silk 叠字（BOOT / 芯片说明）

- **当时**：Wisdom 在 `render_back.png` 上标了红箭头。
- **实际**：**板上真有问题。** `ESP32-C3 + ST25DV64KC + 4.2" BWRY` 写在 `y=73.2`，和 J1 `(40, 73)` 同一高度，字穿座子；`SW1`/`SW2` 位号又压在 `RST`/`BOOT` 上。
- **改法**（只动丝印，**没跑 `gen_pcb.py`**）：坐标收到 `design.py` 的 `SILK_BACK`；现板改 `gr_text`；隐藏 SW1/SW2 位号。
- **教训**：用户标了图，先对 `badge.kicad_pcb` 里的 `gr_text` / footprint `Reference`，不要猜是不是渲染看错。真叠字就拿图和坐标一起问，再改。

## 不要做的事

- 近景没对准就说「3D 看不清」。
- 把拍错当成要改封装、要 `rot=180`、要 Freerouting。
- 确认是板上问题之后不讨论就改铜皮/布线。
- 同类错误只在聊天里认，不写进本文。

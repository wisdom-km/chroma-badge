# 架构决策记录（ADR）

本文记录 4.2 寸彩色墨水屏工牌的关键选型和取舍。所有数字来自 2026 年 9 月检索到的厂商公开资料，价格为参考价。

## 1. 屏幕：4.2 寸四色（BWRY），而不是六色

### 为什么 4.2 寸没有六色可选

E Ink Spectra 6（六色）目前的小尺寸型号只有 1.54"、1.69"、3.6"、3.7"、4.0"、5.9"、7.3"，**没有 4.2 寸**。
最接近的是 4.0 寸 GDEP040E01（600×400，外形 99×66 mm，偏宽屏）和 3.7 寸 GDEH037E01（480×720，58×85.6 mm，竖版）。

### 四色 vs 六色 显示效果

| | 4.2" 四色 GDEM042F86 | 4.0" 六色 GDEP040E01 |
|---|---|---|
| 颜色 | 黑 / 白 / 红 / 黄 | 黑 / 白 / 红 / 黄 / 蓝 / 绿 |
| 分辨率 / PPI | 400×300 / 119 | 600×400 / 180 |
| 全刷 | 20 s（快刷 12 s） | 14–19 s |
| 刷新功耗 | 12 mW（VCI=3.0 V） | < 70 mW |
| 工作温度 | 0–40 ℃ | 0–50 ℃ |
| 裸屏价格 | ≈ ¥70–100 | ≈ ¥100–330 |
| 驱动库 | 佳显官方 ESP32 示例；GxEPD2 支持同系列 HX8717 版 | GxEPD2 不支持 4.0"，需自写 |

**结论**：
- 显示"彩色照片 / 渐变 logo"六色明显更好（PPI 高 50%，色域大一倍）。
- 显示"姓名 + 职位 + 二维码 + 品牌色块"这类工牌内容，四色已经够用，红黄两色足够做强调色和公司标识。
- 六色刷新功耗是四色的 5–6 倍，直接决定了下面的供电方案能不能做薄、能不能无源。

因此 v1 选 **4.2 寸四色**。板子的屏接口是标准 24 pin 0.5 mm FPC，同族的
GDEM042F86（SSD2683ZA，现行型号）、Waveshare 4.2inch e-Paper (G)、GDEY042F51（HX8717，已 EOL）都能接，只需换固件驱动。

## 2. 供电：超薄锂电 + USB-C，而不是纯 NFC 无源

用户偏好是"最好不加电池"。这一节解释为什么自研板 v1 不走无源路线，以及无源路线怎么走。

### 2.1 一次刷新要多少能量

- 屏本身：12 mW × 20 s ≈ 0.24 J，加升压损耗按 ×1.3 → **≈ 0.32 J**
- 若用 ESP32-C3 收图（不开 Wi-Fi，只走 NFC 邮箱）：约 20 mA × 3.3 V × 25 s ≈ 1.7 J
- 若开 BLE 收图：约 3 J；开 Wi-Fi：5–9 J

### 2.2 手机 NFC 能供多少

| 芯片 | 手机场强下可采集功率 | 说明 |
|---|---|---|
| ST25DV64KC（ST） | "数 mW"，无规格值，不稳压 | 只能给 MCU 待机/唤醒，不够刷屏 |
| NTAG 5 boost（NXP） | 低场强模式 ≤ 20 mW，稳压 | 勉强够 12 mW 的屏，MCU 没余量 |
| FM1280（复旦微） | 足够驱动 4.2" 四色 | 佳显 NFC-D4-042 无源驱动板用的就是它 |
| TN2115S2（Chivotech） | 典型 60–150 mW，最高 300 mW | Waveshare 无源系列用它；已停产，佳显 DENFC-M01 因此不再支持二次开发 |

### 2.3 结论

**4.2 寸四色无源 NFC 是可行的，市面上有成品**：大连佳显 NFC-D4-042 驱动板（FM1280，91×77×1.0 mm，
刷新功率 ≤ 15 mW，兼容单色/三色/四色，配 App，官网有原理图），配 GDEM042F86 屏就是一块无电池工牌。

但作为**自研开源 PCB**，无源路线有三个硬伤：

1. 能做到的芯片只有 FM1280 / TN2115S2 这类"NFC 取电 MCU"，公开资料稀少，SDK 不对个人开放，
   Waveshare 的固件是社区逆向出来的。做成开源项目会卡在固件上。
2. 手机必须贴着不动 20–30 s（传图 + 刷新），iPhone 还有 20 s 会话限制需要特殊处理。
3. 无源方案没有 Wi-Fi/BLE，"网站图传"只能靠手机 NFC 中转，无法做到"网页点一下工牌自己更新"。

所以 v1 采用：

- **超薄锂电**：≤ 2.0 mm 厚软包，150–300 mAh，自带保护板（PCM），例如 202545 / 232535 规格
- **USB-C 充电**（沉板式 TYPE-C-31-M-14，Mid-mount，只高出板面约 1.6 mm）。
  座子产品页按 0.75 mm 板；嘉立创无 0.75 档，v1 **按 0.8 mm 打样**（2026-09-14）
- 预留无线充电升级：v2 可在电池仓背面贴 Qi 接收线圈（0.5–1 mm 厚）+ BQ51013B 类接收 IC；
  NFC 能量采集（mW 级）给锂电充电没有实际意义，不做。

### 2.4 续航估算

- 每次更新：1.7–3 J ≈ 0.13–0.23 mAh @3.7 V → 250 mAh 电池 ≈ **1000 次以上更新**
- 待机电流：**待测**。常供电 SO8 ST25DV 规格书典型待机约 76 µA，不能再用「ESP 5 + ST25DV <1 + LDO 5 + 分压 2 ≈ 13 µA / 两年」作为承诺。有板号、温度、电池、USB 断开条件的电流数据之前，禁止写续航年数。

## 3. NFC：ST25DV64KC 动态标签

作用：
- **手机碰一碰唤醒**：RF 场检测 → GPO 拉低 → 唤醒深睡的 ESP32-C3
- **NDEF 引导**：手机读到 URL，自动打开编辑网页（无需装 App）
- **快速传输模式（FTM）**：256 B 邮箱，RF 侧写入速率约 26 kbit/s，一张 400×300×2 bit = 30 KB 的图
  纯 NFC 传输约 10–15 s；也可以只传 Wi-Fi/BLE 配对信息，图走 BLE / SoftAP
- 双接口：I²C 连 MCU，同一片 EEPROM 手机和 MCU 都能读写

天线：PCB 环形天线，位于板上不与电池重叠的区域。ST25DV 内置调谐电容 28.5 pF，
目标电感 ≈ 4.8 µH。手机从**正面**贴屏幕右侧即可（NFC 场可穿透墨水屏玻璃，Waveshare/佳显无源方案的天线同样在屏背面）。

## 4. 主控：ESP32-C3-MINI-1 模组

- Wi-Fi + BLE 5，为后续"网页图传"保留能力
- 原生 USB（GPIO18/19）：USB-C 直接烧录和串口调试，不需要 CH340
- 模组厚 2.4 mm，是整机厚度的决定因素之一；选模组而不是裸片是为了避开天线匹配和认证风险
- 400 KB SRAM，30 KB 帧缓冲无压力

## 5. 厚度堆叠（目标 ≤ 6 mm）

从正面到背面：

| 层 | 厚度 |
|---|---|
| 前框（ABS/PETG 3D 打印，或后期开模） | 0.8 mm |
| 墨水屏 GDEM042F86 | 1.0 mm |
| PCB（2 层，0.8 mm） | 0.8 mm |
| 元件区 / 电池区（取最大：ESP32-C3-MINI-1 2.4 mm；电池 2.0 mm） | 2.4 mm |
| 后盖 | 0.8 mm |
| **合计** | **5.8 mm** |

对比：Waveshare 4.2" 无源 NFC 成品 9.9 mm；佳显 GDN042BW 10.2 mm。

屏 **91×77×1.0** 贴在 PCB 正面；PCB 在屏下加 7 mm 条（USB/按键），所以板是 **91×84×0.8**。FPC 从槽绕到背面插 J1。上表 5.8 mm 是目标叠层；FreeCAD 前框 `BEZEL_T=1.0` 加后腔间隙后整机约 **6.3 mm**。

## 6. 不做的事（v1）

- 固件与手机/网页端：另行开发，本仓库只给出引脚表和接口约定
- 无线充电：v2
- 六色屏：若后续需要，换 4.0" GDEP040E01 需重新设计外壳（99×66 mm）和升压电路参数

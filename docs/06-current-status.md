## 现在最难、最先处理的事项

1. **系统能否可靠恢复与显示。** 先修GPIO深睡、自检入口和显示错误传播，再用实板检验；否则继续写收图会掩盖底层失败。
2. **电源方案能否满足确切屏与电池。** J1.7 Keep Open、XC6220补偿电容、升压参考差异、电池与充电器主料仍需依据与讨论。保持0.8mm已接受决定，但补首件量测。
3. **检查与交付是否可信。** DRC吞错、旧报告误读、缺模型仍导出成功、背面丝印旧包和BOM/DNP歧义都要形成阻断门禁。
4. **手机到屏的真实闭环。** 纯网页NDEF不是FTM邮箱API。选定目标手机和一条路线，先成功传并显示一张非纯色图。
5. **整机验证。** 几何零干涉不能替代实际FPC/电池/胶/连接器包络；续航、充电和装机RF需实测数据。

建议执行顺序：固件与检查门禁 → 硬件待决项/规格冻结 → 单板电源/显示/NFC → 一条手机传图 → 整机机械/RF/功耗。具体验收见合并计划。

## F06 屏脚 7：Keep Open vs GND

**证据**

- 本机 40 页 GDEM042F86 PDF **第 7 页**：脚 1/4/6/7 标 **NC Keep Open**，19 为 VPP Keep Open。见 [local-review.md §5.1](reviews/2026-09-14/local-review.md)。
- 第 29 页参考电路对 6/7 又标 TSCL/TSDA，资料内部不一致；不能用第 29 页自行免除脚表。
- 板上事实：`design.py` J1 pin 7 = `GND`；`route_pcb.py::apply_extra_gnd_pads` 会再缝一刀。原理图、PCB、后处理一致为 GND。
- 不是「已测到损坏」，也不是「NC 接地通常没事所以通过」。

| | 方案 A | 方案 B |
|---|---|---|
| 做什么 | 书面接受偏离：写明精确屏型号+修订+批准人，保持 GND 缝合 | 改 `design.py` 脚 7 为 NC，并改 `apply_extra_gnd_pads`，防止后处理再接地 |
| 影响 | 与第 7 页脚表持续偏离；后续换屏修订要再核 | 改网络。须备份布线指纹 `2d96f275…`，讨论是否 Freerouting；只改网络赋值仍可能要补铜/缝合 |
| 不要 | 用「一般没事」当批准 | 只改原理图不改后处理 |

请选 A / B，并给出屏文件版本（例如 2026-06-17）。

## F07 LDO 近端电容

**证据**

- U4 XC6220B331MR-G；近端 C3=1 µF（0402）、C4=2.2 µF（0603）。Torex 3.0–3.5 V 档对 CIN/CL 成对规定。
- 同网还有 C2/C6；不能把标称值相加当近端补偿，也不能只凭引脚兼容通过。
- 无 DC bias 曲线、无料号锁定。

| | 方案 A | 方案 B |
|---|---|---|
| 做什么 | 锁 C3/C4（及是否计入 C2/C6）的具体料号 + 偏压下有效容值 | 改容值或封装 |
| 影响 | 可能只改 BOM 描述/LCSC，不动铜皮 | 改容值/封装可能要占位；讨论后再说是否重布 |
| 不要 | 用「别人也这么配」代替料号 | 未批准改 `design.py` 网络 |

## F17 电池与充电器

**证据**

- U3 设计字符串仍是 `TP4054 / MCP73831T-2ACI/OT`，两颗不是同一认证条件。
- 电芯未锁；要求自带 PCM；J2 为 JST SHL SM02B-SHLS-TF 1.0 mm 2P。
- 系统从 VBAT 取电，板上无独立负载电源路径管理。无电池 USB 场景**未测**。
- ADR 2.4「13 µA / 两年」无测量支撑（F03，H3 只改表述，不编新续航数字）。

| | 方案 A | 方案 B |
|---|---|---|
| 做什么 | 锁**一颗**充电器主料 + 带 PCM 的电芯料号、极性、J2 配线；写明无电池 USB 允许失败的条件 | 改连接器/充电拓扑（可能动板） |
| 影响 | A 仍可能只改文档/BOM；充电电流现为 R3=5.1 kΩ ≈ 200 mA | B 要单独讨论铜皮 |
| 不要 | 两颗充电器继续并列当已冻结 | 未测就改续航数字 |

请给出：充电器 MPN、电芯料号/厚度、J2 1=VBAT 还是 GND（与 `design.py` 对照）。

## F05 网络类

**证据**

- `design.py::NET_CLASSES` 声明了 Default / Power（0.3 mm）/ NFC（0.5 mm）。
- 工程 `.kicad_pro` 与 PCB 实际只有 Default。Power/NFC 馈线存在 **0.15 / 0.2 mm** 段。
- 不能把「加上分类」写成「现板已满足」。USB D+/D− 网络总长不能当端到端差分（F13，H3 只做路径笔记）。

| | 方案 A | 方案 B |
|---|---|---|
| 做什么 | 批准 **强制最小宽度**（低于则 DRC error）的具体毫米值；首选宽度可另列 | 批准仅「首选宽度、不强制」，现板偏差书面接受 |
| 影响 | 强制值若高于现板最窄段 → 要改线或改规则后重跑 DRC，可能要 Freerouting | 不改铜；生产仍按 Default |
| 不要 | 只往工程里写入分类就声称已合规 | 把 USB 总长差当差分失配去重布 |
